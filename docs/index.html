In the arena

Moments from the combat variant — industrial platforms, lava hazards, and close-range fights.

Install

  1. Download ThreeDensitySetup.exe — a small launcher, not the full game archive.
  2. Run it. It pulls the latest release, installs under your user folder, and drops a desktop shortcut.
  3. Play. Press Esc in-game for the control cookbook and graphics settings. First launch auto-tunes quality to your PC.
